# ⚡ ARSLAN TECH'S – Social Downloader

Ek modern, dark-themed social media video downloader jo TikTok (bina watermark), Instagram, aur Facebook se videos download karta hai.

Built with **Next.js 14 App Router**, **Tailwind CSS**, aur lightweight serverless-friendly libraries.

## 🚀 Features

- 🎬 TikTok – Bina watermark HD video download
- 📸 Instagram – Reels, posts, videos (login ke bina)
- 📘 Facebook – HD aur SD quality options
- 🌙 Dark theme – Purple gradient ke saath modern UI
- 📱 Fully responsive – Mobile, tablet, desktop
- ⚡ Serverless-ready – Puppeteer jaisi bhaari library nahi
- 🔍 Auto platform detection
- 🖼️ Video preview with thumbnail
- 🎚️ HD / SD quality selector

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 14 (App Router) |
| Styling | Tailwind CSS |
| TikTok | @tobyg74/tiktok-api-dl |
| Instagram | instagram-url-direct |
| Facebook | fb-downloader-scrapper |
